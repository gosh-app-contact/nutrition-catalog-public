# nutrition-catalog-public

Repo public de distribution des catalogues Gosh (nutrition + exercices), servi via GitHub Pages.

Ce repo est généré automatiquement par le Back Office Gosh — ne pas éditer son contenu à la main.

- `nutrition/manifest.json`, `nutrition/catalog.json.gz` — catalogue nutrition
- `exercises/manifest.json`, `exercises/exercises.json` — catalogue exercices

La source de vérité reste le catalogue du Back Office (repo privé `gosh-app-contact/gosh-app`).
